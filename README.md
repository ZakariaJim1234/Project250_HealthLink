<h1>HealthLink</h1> HealthLink is an Android-based mobile application designed to provide quick and reliable access to healthcare information in the Sylhet region. The app enables users to find nearby hospitals, view doctor profiles, and access emergency contact details. It also allows health centers to manage and update their own information, ensuring accurate and real-time data availability.<br>

<h1>Features</h1><br>

User Features:<br>
Search for local hospitals in the Sylhet region.<br>
View hospital details including name, location, and emergency contact numbers.<br>
Browse doctor profiles with specialization, chamber location, and appointment details.<br>
Access emergency contact numbers quickly.<br>
Location-based search for nearby healthcare centers.<br>

HealthCenter Features:<br>
Create and manage HealthCenter accounts.<br>
Update hospital and doctor information.<br>
Maintain accurate and real-time data.<br>

General Features:<br>
User-friendly and intuitive interface.<br>
Fast access to critical healthcare information.<br>
Regular database updates for accuracy.<br>
